# Joseph Paguirigan — Portfolio

Personal design portfolio. Single-page HTML, no build step.

## Deploy

Drop these files into a GitHub repo and enable **Settings → Pages → Deploy from a branch → main / (root)**.

## Files

- `index.html` — main portfolio
- `case-sce.html` — SCE case study (loaded in modal from main page)
- `case-sce-assets/` — case study screenshots
- `portfolio-*.jpg` — gallery images
